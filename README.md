# Hotel-Booking-Summary-Tool
Agile team project to develop a modular Python tool for cleaning, processing, and summarizing hotel booking data, with a focus on incremental development, collaboration, and reusable data analysis functions.
## Project Overview

The Hotel Booking Summary Tool is a Python-based Agile team project developed to process, clean, and summarize hotel booking data from the `hotel_bookings.csv` dataset.

The project focuses on producing useful booking summaries and insights through modular, reusable, and documented Python functions.

This project is being developed incrementally during a one-week Sprint using Agile practices, GitHub for version control and collaboration, and Taiga for Sprint and task management.

## Sprint Goal

Develop a functional and reusable Python Hotel Booking Summary Tool that cleans and processes the provided hotel booking dataset and produces meaningful booking, cancellation, hotel/market segment, and stay/rate summaries while demonstrating effective Agile collaboration through GitHub and Taiga.

## Agile Workflow

The team follows a branch-per-feature workflow.

Each User Story is developed in a dedicated feature branch and integrated into the main branch through a Pull Request and peer review.

Example:

US-01 → Feature Branch → Commits → Pull Request → Peer Review → Merge

Git commits and Pull Requests reference the corresponding User Story ID to maintain traceability between Taiga and GitHub.

## Project Structure

- `data/` - Hotel booking dataset
- `src/` - Python source code and reusable functions
- `tests/` - Tests and validation
- `main.py` - Main entry point of the application

## Dataset

The project uses the provided `hotel_bookings.csv` dataset. Each row represents a hotel booking and contains booking, guest, stay, cancellation, and rate-related information.
